# Trading Workbench / framework map

**Live site:** https://lawliet73.github.io/trading-workbench-showcase/

**Project owner:** Kalab Alemayehu ([GitHub](https://github.com/Lawliet73)).

Trading Workbench is a personal learning and engineering project exploring quantitative trading, systematic research and reproducible experimentation. This repository presents an interactive showcase, not the underlying private research platform.

## What the project explores

- Reproducible market-data and experiment workflows.
- Statistical validation, overfitting and look-ahead bias.
- Research lifecycle design and evidence-based engineering.
- Educational explanations of quantitative research concepts.

The project distinguishes implemented functionality from tested evidence and proposed work. It is an ongoing learning exercise, not investment advice or a claim of profitable performance.

## About the showcase

The website includes interactive diagrams, educational material and an English/German research companion. The companion can make mistakes; verify its explanations against the published educational sources.

Diagrams use [Archify](https://github.com/tt-a1i/archify). Development and documentation use AI assistance.

This repository is public. Publication must be limited to reviewed showcase material, including source assets and generated knowledge.
