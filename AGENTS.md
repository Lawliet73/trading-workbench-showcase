# Showcase contributor instructions

This repository is public. Treat every tracked file, commit, branch, issue, pull request and generated artifact as publicly accessible.

Publish only approved showcase material. Keep private research, personal data, credentials, internal source references and unpublished implementation plans in the private workspace. Review the complete publication payload before pushing it, including generated knowledge and assets. UI visibility is not an access control.

Use feature branches and review changes before merging. Run existing tests and verify desktop and mobile behavior for interface changes. Merge only with explicit owner approval.
